# AURABUDS — Premium Wireless Audio 🎧

AURABUDS is a modern **wireless earbuds e-commerce website** built with React, Vite, and Tailwind CSS. The project focuses on a premium audio-brand experience with smooth animations, responsive layouts, product browsing, cart functionality, checkout, authentication UI, and a cinematic preloader.

## ✨ Features

- 🎧 Premium AURABUDS branding
- 🏠 Modern animated home page
- 🛍️ Product listing with 12 earbuds
- 🔎 Product search
- 🏷️ Category filtering
- ↕️ Price and rating sorting
- 📦 Product details page
- ⭐ Ratings and customer reviews
- ❤️ Wishlist functionality
- 🛒 Add to Cart
- ➕➖ Cart quantity controls
- 💰 Cart total and pricing
- 🚚 Free shipping calculation
- 💳 Checkout page
- ✅ Order confirmation
- 🔐 Login page
- 📝 Signup page
- ℹ️ About page
- 📩 Contact page
- 📱 Responsive mobile/tablet/desktop design
- ✨ Smooth hover animations
- 🎬 Premium preloader animation
- 🔝 Fixed navigation bar
- 📜 Smooth page scrolling
- 👁️ Hidden scrollbar
- 🌑 Premium black-and-white visual theme
- 🌐 Browser favicon/logo
- 💾 LocalStorage for cart, wishlist, user and order data
- 🚫 No unnecessary alert popups

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript ES6+
- HTML5
- CSS3
- React Router DOM
- Lucide React
- LocalStorage
